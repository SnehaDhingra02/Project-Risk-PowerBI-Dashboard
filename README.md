# 📊 Project Risk Power BI Dashboard

## 📌 Project Overview

This project is an interactive **Project Risk Analysis Dashboard** developed using Microsoft Power BI.

The dashboard provides a clear and interactive view of project performance, project status, risk levels, and key project metrics. It helps users quickly identify high-risk projects and monitor overall project health.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## 📈 Dashboard

![Project Risk Dashboard](dashboard.png)

## 🔍 Key Features

- 📌 KPI cards for important project metrics
- ⚠️ Project risk analysis
- 📊 Risk level distribution
- 📋 Project status monitoring
- 🔎 Interactive slicers and filters
- 📈 Visual analysis of project performance
- 🎯 Identification of high-risk projects

## 💡 Key Insights

- Provides an overview of the total number of projects.
- Helps identify projects with higher risk levels.
- Allows users to analyze project status interactively.
- Provides a quick summary of important project KPIs.
- Makes project risk monitoring easier through interactive visualizations.

## 🚀 How to Use

1. Download the `.pbix` file.
2. Open it using **Microsoft Power BI Desktop**.
3. Use the available slicers and filters to explore the dashboard.
4. Interact with the visualizations to analyze project risks and performance.
